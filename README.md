🏡 Bengaluru House Price Predictor

A machine learning project that predicts house prices in Bengaluru using cleaned and preprocessed real-estate data.

📌 Overview

This project uses a dataset of Bengaluru house prices and applies data cleaning, feature engineering, and machine learning to build a price prediction model.
The goal is to create an accurate and interpretable model for estimating property prices based on location, size, number of bathrooms, and other features.
